# 知序使用教程与说明

把课件、讲义和自己的理解，整理成一个可以随时查找、逐步补充的课程知识库。

**不想从头读？可以把整份教程下载下来，交给 AI 阅读。** 点击上方「下载 Markdown」，把下载的教程与课程资料一起发给能够读取文件的 AI，再复制下面这段话。AI 可以据此整理导入文件，并告诉你下一步在网页上怎么操作。

```text
请先完整阅读我上传的《知序使用教程与说明》，了解网页功能和导入格式，
再帮我把课程资料整理成可导入的文件，并用简单步骤告诉我如何导入。

课程名称：[填写课程名]
所在学期：[例如：大三上]
主要资料：[填写主要讲义或教材的文件名]
整理范围：[建议先做第一章]
资料位置：[已上传的文件，或你能够读取的本地文件夹路径]
已有知识库：[全新使用，或同时上传我导出的 JSON 备份]

如果已有备份，请沿用已有编号，避免重复创建课程和知识点。
请先读资料，保留定理条件、公式和来源，理解内容后再安排目录分组。
按照教程中的格式生成 JSON，并检查文件能否解析、上级引用是否完整。
读不到的资料或不确定的内容请明确指出，不要猜测。
只生成文件并说明操作步骤，不要把我的课程资料发布到公共网站。
```

下载文件包含完整正文、提示词和格式示例；示例图以图片链接保留，需要联网查看。AI 即使不能查看图片，也可以按文字说明和格式示例处理资料。教程本身可以直接分享给朋友；私人课程资料请只交给你愿意使用的 AI 工具。

想自己上手，也可以从一门课的一章开始：手动记一条笔记，或按下面的步骤导入资料。

## 1. 快速开始

**手动开始：** 添加学期 → 添加课程 → 添加章节 → 添加知识点，填写后保存。

**借助 AI 开始：** 把资料提供给能够读取文件的 AI → 使用下方提示词 → 得到课程 JSON → 在左侧「导入与备份」选择「合并导入 JSON」→ 查看预览 → 点击「确认合并」。

选择文件后出现的是导入预览，**还需要点击确认，才会保存**。

![导入入口示例：左侧的导入与备份打开后，可选择合并导入 JSON 或更新知识点 JSON。](https://beiguguguc.github.io/course-atlas/docs/images/guide-import.jpg "图 1 · 添加新内容选「合并导入 JSON」；替换已有知识点选「更新知识点 JSON」。")

如果你已经在网页中建过课程，先「导出完整知识库」，把导出的 JSON 与资料一起提供给 AI，让它沿用已有编号，避免重新创建同名学期或课程。

## 2. 你可以在这里做什么

| 想做的事 | 使用方式 |
| --- | --- |
| 整理不同学期的课程 | 按「学期 → 课程 → 章节 → 知识点」逐层建立内容 |

## 3. 内容保存在什么地方

内容保存在**当前网址、当前设备、当前浏览器**的本地数据库中，普通刷新后仍会保留。

- 网站公开网址可以发给朋友；朋友打开后，使用的是他自己的知识库，看不到你的笔记。
- 相同网址在电脑 Edge、电脑 Chrome 和手机浏览器中，是相互独立的数据。
- 本地预览地址与公开网址也不共用数据。
- 当前没有账号登录、自动云同步或多人共同编辑。跨设备使用需要自行导出、导入 JSON。
- 换浏览器、换网址、重装系统或清理站点数据前，请先导出备份。无痕模式中的保存方式也不适合长期存放笔记。

分享网址是在分享这个工具；分享你的课程内容，需要额外分享导出的 JSON 文件。

来源文件栏只记录文件名称，填写它不会把原来的 PDF、PPT 或本地文件夹上传到网站。

## 4. 手动记录与整理知识点

进入一个章节，点击「添加知识点」。建议这样填写：

- **标题：** 用来快速定位的概念、定理或方法名称。
- **简要说明：** 一句话概括核心内容。
- **类型：** 概念、定理、模型、方法、理解或笔记。
- **总览中的分组路径：** 例如「空间结构 > 范数及其性质」，用 `>` 分隔主题与子主题，最多 5 层。每层名称最多 80 字，不包含分隔符 `>`。
- **定理／一般形式：** 写清定义、公式、适用条件和必要解释。
- **例题与解答：** 分别填写题目和解答，复习时可以先思考再展开。
- **资料来源：** 记下文件名和页码，方便回查。
- **补充说明：** 记录老师补充、易错点或自己的理解。

编辑器中的「查看预览」可以检查排版，点击保存后才写入知识库。

![知识点阅读示例：在例题与解答页查看题目，点击展开解答后查看公式和解题过程。](https://beiguguguc.github.io/course-atlas/docs/images/guide-example.jpg "图 3 · 正文与例题分开阅读。可以先独立思考，再展开解答；右侧保留资料来源。")

总览中的主题和子主题是目录归类，不会改变知识点原本所属的章节。没有设置分组的知识点仍然可以正常浏览；设置分组后，总览会显示它的层次。

公式写法示例：行内公式用 `$x^2$`，独立公式用 `$$` 包围。这里支持常见 LaTeX 数学公式，不处理完整的 LaTeX 文档、宏包或外部 `.tex` 文件。

## 5. 用 Markdown 导入一条笔记

先进入要放入知识点的**章节**，点击「导入 Markdown」，选择 `.md` 文件。文件会先进入编辑预览，检查后点击保存。

一份 Markdown 文件会创建一个知识点。重复导入同一份 Markdown 也会创建新知识点；要修改原来的内容，请直接编辑，或使用 JSON 更新。

可以让 AI 按下面的模板输出，也可以自己写：

```markdown
# 数列收敛

> 用任意小的误差描述数列接近一个确定数的过程。

## 目录分组
极限与连续 > 数列极限

## 定理与一般形式
对任意 $\varepsilon>0$，存在正整数 $N$，使得当 $n>N$ 时，
有 $|x_n-a|<\varepsilon$，则称 $x_n$ 收敛于 $a$。

## 例题 1：一个简单数列
说明为什么 $1/n$ 收敛于 $0$。

### 解答
给定 $\varepsilon>0$，取正整数 $N>1/\varepsilon$。
当 $n>N$ 时，有 $|1/n|<\varepsilon$。

## 来源
来源文件：示例讲义.pdf
页码：3

## 补充说明
这是一条演示笔记，可以改成自己的课程内容。
```

第一行 `# 标题` 作为知识点标题；首个引用行可作为简介。目录分组、正文、例题、解答、来源和补充说明会分别进入对应位置。

Markdown 文件最大 1MB。常见标题、列表、表格、代码和公式可以展示；原始 HTML 不会执行。随文件携带的内嵌 PNG、JPEG、WebP 图片可以直接显示、点击放大，并随 JSON 备份一起保存。普通外链图片和本地文件路径仍显示说明文字；仅粘贴电脑上的图片路径不会把图片带入知识库。

## 6. 让 AI 整理整个资料文件夹

适合整章、整门课的 PDF、PPT、教材节选和笔记。选择能够读取这些文件的 AI 工具；如果它不能访问本地文件夹，请在该工具中上传资料后再使用提示词。

先指定主要讲义和整理范围，避免多份教材的约定混在一起。第一次可以从一章开始，检查后再继续。

**复制下面的提示词，把方括号换成自己的信息：**

```text
请阅读我的课程资料，整理成可以直接导入“知序”知识库的 JSON 文件。

网站：https://beiguguguc.github.io/course-atlas/
数据格式说明：https://beiguguguc.github.io/course-atlas/docs/DATA-STRUCTURE.md

资料文件夹或已上传的资料：[填写路径或文件名称]
所在学期：[例如：大三上]
课程名称：[填写课程名称]
主要资料：[指定主要讲义或教材]
整理范围：[例如：先整理第一章]
已有知识库备份：[如有，请使用我提供的 JSON；没有则为全新知识库]

请先阅读数据格式说明，检查资料是否可以读取，再完整阅读指定范围。
保留主要资料的术语、符号、定理条件和章节顺序。
读不到、缺页或存在疑问的内容请明确标注，不要猜测。

按照“学期 → 课程 → 章节 → 知识点”组织内容。
每个知识点包含标题、简要说明、正文、适用条件和必要解释；
根据实际内容安排合适的例题，题目与解答分别保存。
自拟例题注明“自拟”，不要把补充内容冒充讲义原文。
正文使用 Markdown，公式使用 $...$ 或 $$...$$，
注意 JSON 中反斜杠的正确转义，并填写来源文件和页码。

理解知识之间的关系，为每个知识点填写 outlinePath，
例如 ["知识主题","子主题"]，最多5层，每层1–80字。
根据实际内容归类，不要只按标题关键词机械分组。
outlinePath 只负责目录分组，parentId 仍指向所属章节。

文件使用 {"schemaVersion":1,"nodes":[...]} 格式。
level：学期0、课程1、章节2、知识点3。
知识点使用 body 保存正文，examples 保存例题，outlinePath 保存分组。
如果已有知识库，请沿用已有 ID 和 parentId，保留文件范围之外的内容。
如果是全新知识库，请包含完整的学期、课程和章节节点。
为内容使用稳定、唯一的 ID，方便之后补充和更新。

检查 JSON 可以正常解析、ID 唯一、上级引用完整，
并核对知识点有无遗漏、重复，以及公式和定理条件是否准确。
交付一个可直接导入的 .json 文件，以及简短的目录与疑问说明。
资料和生成的课程内容保留在本地，不上传到公共仓库。
```

拿到文件后，在「导入与备份」中选择「合并导入 JSON」，确认预览后再点击「确认合并」。展开课程总览即可查看整理出的知识层次。

## 7. 更新已有内容与调整分组

先区分你要做哪一种操作：

| 目的 | 应该怎么做 |
| --- | --- |
| 添加新的课程、章节或知识点 | 合并导入 JSON；相同编号的内容会保留 |
| 替换已有知识点的正文和例题 | 更新知识点 JSON；沿用原 ID，提供完整的新版记录 |
| 只调整总览中的主题、子主题 | 合并导入只包含 `outlineUpdates` 的分组文件 |
| 整个知识库回到某份备份 | 恢复完整备份；会整体替换当前内容，需要勾选确认 |

**合并导入不会覆盖同编号的旧正文。** 如果你的目的是补充正文和例题，需要选择「更新知识点 JSON」。

覆盖更新时，知识点记录会整体替换，例题列表也以新版为准。文件需要带上想保留的完整正文、例题、来源和备注，省略的可选内容可能被清空。普通内容更新未提供 `outlinePath` 时保留原分组；提供空数组才取消分组。手动建立的知识点关联会保留。

有实际内容覆盖或分组调整时，网站会自动保存最近一次更新前的本地整库备份，可在「导入与备份」下载。它只保留最近一次，不代替你长期保存的备份文件。

**补充已有知识点时，可以给 AI 这段提示词：**

```text
我提供了知序知识库导出的 JSON，以及需要参考的课程资料。
请只补充这门课的这些知识点：[填写课程、章节或知识点范围]。
先阅读格式说明：
https://beiguguguc.github.io/course-atlas/docs/DATA-STRUCTURE.md

沿用已有知识点的 ID、parentId 和层级。
阅读资料后补充正文、条件说明或合适的例题与解答，保留已有正确内容、
来源、自注和目录分组。原有内容与资料冲突时，单独指出原因。

输出用于“更新知识点 JSON”的文件，只包含本次实际更新的知识点。
每条记录带上更新后完整的正文、例题、来源和备注，
例题列表包含需要保留的旧题，不要把完整记录误写成局部补丁。
不要包含删除操作，也不要改变原有 ID 或章节位置。
附上简短的修改清单和待核对问题。
```

**只改目录层次时，使用这一段：**

```text
请根据我提供的课程资料和已有知识库 JSON，重新梳理指定课程的总览层次。
整理范围：[填写课程或章节]。
先阅读格式说明：
https://beiguguguc.github.io/course-atlas/docs/DATA-STRUCTURE.md

理解内容后整理为“知识主题 → 子主题 → 具体知识点”，
保留全部已有知识点，不修改正文、例题、备注、来源和章节位置。
分组最多5层，每层1–80字，使用原知识点 ID。

输出只调整目录的文件：
{"schemaVersion":1,"nodes":[],"outlineUpdates":[
  {"id":"已有知识点的ID","outlinePath":["主题","子主题"]}
]}

为需要调整的知识点逐条填写真实 ID 和路径，
检查无重复编号、无遗漏、无未知知识点，并附上简短目录说明。
我会使用“合并导入 JSON”应用此文件。
```

仅分组文件不会新建知识点，所以预览中「新增 0 条」可能完全正常。请同时查看分组调整数量，点击确认后再回到总览查看。重复应用相同分组不会重复添加内容。

## 8. 建立知识点关联

当你发现两门课的概念相似，或者一个定理在另一章中有应用，可以把它们连起来：

1. 打开一个知识点，找到正文下方的「关联知识点」。
2. 点击「添加关联」，按名称搜索，或选择课程缩小范围。
3. 选择另一个知识点，可填写一句关联说明，然后保存。
4. 两边都会出现关联，点击即可跳转；页面顶部可以返回来源知识点。

同一对知识点只需要建立一次。可以修改说明或移除关联；移除关联只断开连接，不删除任何一端的正文。

## 9. 备份、迁移与分享

在「导入与备份」点击「导出完整知识库」，保存得到的 JSON 文件。完整备份包含学期、课程、章节、知识点、例题、目录分组和知识点关联。

**换设备或浏览器：** 在原浏览器导出，在新设备打开相同网站，再合并导入备份。

**把课程发给朋友：** 分享导出的 JSON 文件，由朋友在自己的浏览器导入。完整知识库文件会包含你所有课程；如果只想分享其中一门，可以请 AI 根据编号和层级提取这门课及其必要上级，关联仅保留两端都在文件中的记录。

**恢复整库：** 选择「恢复完整备份」会用文件替换当前全部课程、笔记和关联。操作前先导出当前备份。没有关联信息的旧备份，恢复后关联为空。

新手一般使用「合并导入 JSON」；需要覆盖已有知识点时用「更新知识点 JSON」。只有明确想整体回到备份状态时，才使用恢复功能。

## 10. 常见问题

### 为什么朋友打开网址看不到我的内容？

网址分享的是工具，笔记在各自浏览器中独立保存。需要额外分享课程 JSON，朋友导入后才能看到内容。

### 为什么手机和电脑不同步？

当前没有自动云同步或账号系统。可以用导出、导入 JSON 手动迁移。

### 导入显示 0 条，是不是失败了？

先看是哪一种文件：同编号的普通合并会保留旧内容；只调整分组的文件也不会新增知识点。确认文件名称、实际更新或分组调整数量，并点击确认按钮。若提示全部已保留或内容相同，重复导入不会再次产生变化。

### 总览只有一串知识点，没有主题和子主题？

这些知识点尚未设置分组。可以在知识点编辑页填写分组路径，或让 AI 生成 `outlineUpdates` 分组文件。分组文件需在当前浏览器已有对应知识点后应用。

### 网页更新了，我还是看到旧界面？

先按 Ctrl + F5 强制刷新；Mac 可用浏览器的重新载入操作配合缓存刷新。普通刷新和强制刷新不会清空笔记。更新前用旧页面导入的新格式文件可能没有生效，刷新后重新选择正确文件并确认导入。无需清理站点数据。

### 只把一个文件夹路径发给 AI，它能读到吗？

取决于所用的 AI 工具是否有本地文件访问能力。不能访问时，在那个工具中上传文件或压缩包；本网页本身不读取原始课件文件夹，也不会自动替你调用 AI。

### 导入提示找不到上级或知识点？

检查是否缺少所属学期、课程或章节，以及文件中的 ID 是否来自当前知识库。已有内容应使用原编号；新知识库需要一并包含完整上级。分组文件不能代替知识点正文文件。

### Markdown 与 JSON 应该选哪个？

单条笔记、手动编写与检查内容，用 Markdown 很方便；批量建立课程、覆盖已有知识点、单独调整分组、备份迁移，用 JSON 更合适。

## 11. 写给 AI 的格式与示例

详细规则见 [课程数据结构说明](https://beiguguguc.github.io/course-atlas/docs/DATA-STRUCTURE.md)。需要交给其他 AI 时，可以下载这份 Markdown 使用手册，一起提供。

公共字段中，`id`、`parentId`、`level`、`title` 为必填。学期的 `parentId` 为 `null`，其他内容指向上一级；编号使用字母、数字、下划线或短横线，最多 120 字符。标题最多 100 字符。

知识点可填写：`description` 简介、`kind` 类型、`body` 正文、`examples` 例题、`sourceFile` 来源文件、`sourcePage` 页码、`supplement` 补充说明，以及 `outlinePath` 目录分组。

下面是一个可以在空白知识库中合并导入的完整示例，上级节点都已包含。它是演示数据，不代表任何人的实际课程：

```json
{
  "schemaVersion": 1,
  "nodes": [
    {"id":"guide-term","parentId":null,"level":0,"title":"示例学期","order":1},
    {"id":"guide-course","parentId":"guide-term","level":1,"title":"示例课程","order":1},
    {"id":"guide-chapter","parentId":"guide-course","level":2,"title":"第一章 极限","order":1},
    {
      "id":"guide-topic-limit",
      "parentId":"guide-chapter",
      "level":3,
      "title":"数列收敛",
      "description":"用任意小的误差描述收敛。",
      "order":1,
      "kind":"概念",
      "body":"对任意 $\\varepsilon>0$，存在正整数 $N$，使得当 $n>N$ 时有 $|x_n-a|<\\varepsilon$。",
      "outlinePath":["极限与连续","数列极限"],
      "examples":[{
        "id":"guide-example-one-over-n",
        "title":"一个简单数列（自拟）",
        "prompt":"说明 $1/n$ 收敛于 $0$。",
        "solution":"给定 $\\varepsilon>0$，取正整数 $N>1/\\varepsilon$。当 $n>N$ 时，有 $|1/n|<\\varepsilon$。"
      }],
      "sourceFile":"示例讲义.pdf",
      "sourcePage":"3",
      "supplement":"这是演示内容，可替换为自己的理解。"
    }
  ]
}
```

JSON 单个文件最大 10MB，每批最多 10000 条内容。普通 JSON 的同编号合并不会重复添加；更新按编号匹配，不按标题匹配。整理完成后，请核对原资料中的关键公式、定理条件和例题结论。
